# Phase 3 Composite CDC + HID Touch: built 2026-07-14

The Phase 3 image is `b3/pico_h_phase3_composite_touch.uf2`.

- USB identity: `VID_CAFE&PID_4021`.
- Interfaces: CDC serial command channel plus the single-contact HID touchscreen proven in Phase 2.
- Safe idle state: a release report only. No touch is emitted unless the host sends `DOWN`, `MOVE`, or `UP` through CDC.
- CDC maintenance: `HELLO 1`, `PING`, `STATUS`, `DOWN`, `MOVE`, `UP`, `CANCEL`, `RESET`, and `BOOTSEL`.
- `BOOTSEL <seq>` acknowledges, releases any contact, then switches to `RPI-RP2`; later firmware updates will not require the board button.
- First hardware verification after flashing must use only `tools/cdc_phase3_smoke_test.ps1`; it sends no touch-down command.

## Phase 3 Result: verified 2026-07-14

- Windows enumeration passed as `USB Composite Device`, `USB Serial Device (COM5)`, and `HID-compliant touchscreen` under `VID_CAFE&PID_4021`.
- CDC smoke test passed with `tip=0` before and after `CANCEL`.
- The first live LOGIN run exposed a valid firmware flow-control defect: CDC could receive a MOVE while the prior HID transfer was pending. Firmware now uses a 64-report ordered HID queue; the fixed UF2 SHA-256 is `793131125B0B57C67341B032FE8C62AD1F52F5CEA88E17D47B419AA22CBA380F`.
- Remote `BOOTSEL 900` was verified and used to update the fixed firmware without the physical button.
- The second live run exposed the host's foreground-only guard as too strict for non-overlapping grid windows. The host now accepts an unfocused target only when `WindowFromPoint` confirms the exact touch coordinate belongs to that target.
- Final LOGIN test passed: slot 1, 250 events, 92 gestures, 768x432 recording scaled to 512x288, 1.5-second per-slot cooldown, 152.7 seconds elapsed, no CDC/HID/visibility error.
- Post-test smoke confirmed `tip=0` and `queued=0`.
